# Статус сборки

Актуальная Windows-сборка 1.10 временно проверяется через миграционную сборочную ветку исходного репозитория из-за того, что GitHub Hosted Runner `windows-latest` не назначается (job завершается до первого шага, `runner_id=0`).

До успешного Windows smoke-test версия 1.10 не считается опубликованным релизом.

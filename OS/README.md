# Клиенты «Лешего» по операционным системам

Каталог `OS/` содержит только приложения-клиенты для доступа к одному серверному ядру «Лешего». Код ядра остаётся в `src/`; существующие установщики и Windows-сценарии в корневом `windows/` пока сохраняются ради совместимости.

| Каталог | Назначение | Состояние |
| --- | --- | --- |
| `OS/android/` | Нативный клиент Android 14+ | Черновик, не собран и не проверен на устройстве |
| `OS/IOS/` | Будущий клиент iPhone/iPad | Не реализован |
| `OS/Linux/` | Клиент Linux, включая ARM64/Raspberry Pi | Планируется отдельно, Issue #303 |
| `OS/windows/` | Будущий клиент Windows | Не реализован в этом каталоге |
| `OS/mac/` | Будущий клиент macOS | Не реализован |

Правило именования: **пути и Git-ветки не должны содержать имя разработчика или агента**. Для веток использовать нейтральные префиксы `feature/`, `fix/`, `docs/`.

Не путать клиентские приложения с сервером, установщиком или системными скриптами. Перенос таких существующих компонентов требует отдельного аудита ссылок и сборки.


## Сетевые оповещения (общее требование для всех клиентов)
- При подтверждённой потере интернета показывать и при доступном локальном голосовом выводе произносить: «Нет подключения к интернету».
- При наличии интернета, но потере связи с сервером «Лешего» использовать другое сообщение: «Нет связи с сервером Лешего». Проверка конкретного сервера доступна только после реализации клиентского транспортного соединения.
- Повторять предупреждение не на каждом сетевом событии, а при переходе состояния. При восстановлении соединения переподключаться автоматически; не придумывать ответы в период недоступности.
- Отсутствие интернета не запрещает работу с локально доступным сервером по LAN. Если устройство не имеет аудиовыхода или офлайн-TTS, показывать статус текстом.


### Текущее состояние клиента Android
Проверка `GET /v1/status` по доверенному HTTPS-адресу — только диагностика доступности; не считать её авторизацией или полноценным диалогом. Код серверных маршрутов и авторизации находится вне `OS/`.

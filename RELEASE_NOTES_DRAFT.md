# Черновик примечаний к выпуску Leshy 1.10.15

## Browser Platform

- Добавлен универсальный Browser Agent: Browser Use для семантического веб-исследования и Playwright для детерминированных действий.
- Родная локальная LLM Лешего подключена к Browser Use без обязательного платного API.
- Read-only режим Browser Use теперь технически отключает click/input/send_keys/select_dropdown, произвольный JavaScript и локальный file I/O, а не полагается только на prompt.
- Добавлен Human Approval Gate: одноразовое подтверждение `mutate`, `commit` и `financial` действий; оплата требует суммы/валюты и отдельного подтверждения.
- Web UI показывает `Подтвердить` / `Отмена` и отдельную кнопку подтверждения оплаты.
- Результаты поиска вариантов сохраняются в SQLite и восстанавливаются после перезапуска.
- Browser state/cookies сохраняются в отдельном профиле; CAPTCHA/challenge/2FA не обходятся.
- Усилена доменная изоляция: явный allowlist нельзя расширить стартовым URL.

## Интеллектуальная память и GraphRAG

- Добавлен отдельный модуль `intelligent-memory`: релевантное извлечение памяти по текущему запросу, ранжирование по важности и свежести, контролируемое автосохранение долговременных предпочтений.
- Автоматическое сохранение блокируется для сообщений, похожих на пароли, токены, CVV, SMS-коды, приватные ключи и другие секреты.
- Добавлен локальный `knowledge-graph`: проверенные знания и память пользователя связываются через концепты и используются как GraphRAG-контекст.
- Добавлены команды `/memory запрос` и `/graph запрос`.

## Команда подагентов

- Добавлен модуль `agent-orchestrator` с ролями Исследователь, Архитектор, Критик и Оптимизатор.
- Подагенты возвращают рабочие отчёты координатору, а origin-узел формирует единый пользовательский ответ без раскрытия внутреннего chain-of-thought.
- Команду можно вызвать через `/agents задача` или естественной фразой вроде «используй команду агентов».
- При наличии двух и более кластерных узлов роли распределяются между компьютерами и выполняются параллельно.

## Распределённый кластер

- Добавлен модуль `distributed-cluster`, объединяющий CPU, GPU, NPU, RAM и локальные модели нескольких доверенных компьютеров.
- Реализовано автоматическое LAN discovery через подписанные UDP broadcast-пакеты.
- Межузловые задачи передаются через HMAC-SHA256 подписанный HTTP transport.
- Планировщик учитывает очередь, загрузку, доступную RAM, CPU и наличие ускорителей.
- Удалённый кластер не получает произвольный shell-доступ: разрешён только безопасный набор вычислительных задач.
- Майнинга, Proof-of-Work и монетизации нет — вычисления используются только для полезной работы Лешего.
- Добавлены `/cluster`, `GET /v1/cluster/status`, `POST /v1/cluster/refresh` и внутренний `POST /v1/cluster/task`.

## Инструменты и документы

- Добавлен MCP v2 Tools Gateway с реестром permissions и approval для опасных инструментов.
- Добавлен изолированный MCP/Skills Extension Marketplace: pinned package, лицензия, HTTPS repository, отдельный venv, health-check и rollback неудачной установки.
- Добавлен Document Intelligence на MarkItDown с локальными fallback для PDF/текста.
- Existing Computer Use представлен отдельным модулем в настройках.

## Проверки

- Существующий набор regression/CI-проверок сохранён.
- Для этой серии изменений сборку и автотесты вручную не запускали; проверка остаётся за локальным/CI-контуром владельца.

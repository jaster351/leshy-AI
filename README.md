# Леший AI

Леший — самостоятельный локальный AI-ассистент с долговременной памятью, интернет-исследованием, Web/Windows интерфейсом, Telegram, голосом, Computer Use, Browser Platform, Marketplace и автономными заданиями.

## Browser Platform

В версии 1.10.12 Browser Platform объединяет:

- Browser Use — интеллектуальное исследование и работа с динамическими сайтами;
- Playwright — детерминированные browser-workflow и существующие browser-skills;
- Human Approval Gate — обязательное одноразовое подтверждение изменения данных, заказа/бронирования и отдельное подтверждение оплаты;
- сохранение browser session и восстановление найденных вариантов после перезапуска;
- MCP v2 Tools Gateway и изолированный MCP/Skills Extension Marketplace;
- MarkItDown Document Intelligence;
- существующий Computer Use как отдельный desktop-модуль.

Первый запрос «купи…» или «забронируй…» сначала выполняет поиск и сравнение. Леший не совершает внешнее обязательство без подтверждения пользователя и не обходит CAPTCHA/2FA.

Подробности: `docs/BROWSER_AGENT.md`.

## Принципы

- локальная работа без обязательного внешнего AI API;
- открытые и юридически допустимые зависимости;
- одна личность и одна память LeshyBrain вместо набора независимых ассистентов;
- безопасное использование инструментов с журналированием, разрешениями и Human Approval Gate;
- русский язык обязателен, UI развивается как мультиязычный;
- автоматические regression/eval проверки критических сценариев.

Полная архитектура и дополнительные возможности описаны в документации проекта.

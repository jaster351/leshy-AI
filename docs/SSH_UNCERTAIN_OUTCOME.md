# SSH: неопределённый результат команды

В модуле `superagent_ssh_terminal.py` результат SSH-команды имеет поле
`outcome`: `confirmed` означает, что получен полный exit code, а
`unknown` — что вывод обрезан или exit code отсутствует.

Если соединение оборвалось или время ожидания истекло после отправки команды,
модуль записывает обезличенный аудит с хешем команды и выбрасывает
`SSHOutcomeUnknown`. Повторять команду автоматически запрещено: удалённый
эффект мог уже произойти. Пользователю нужно показать неопределённость и
предложить сначала проверить состояние сервера безопасным чтением.

Этот этап НЕ реализует постоянный PTY-терминал, прерывание удалённого процесса,
Web/Windows UI, а также RDP. Требуются отдельные проверки маршрутизации,
авторизации, отмены и настоящие E2E на Windows/Linux.

Регрессионные сценарии находятся в
`tests/test_ssh_terminal_uncertain_outcome.py`; они используют имитации
транспорта и не подтверждают работу реального SSH-сервера.

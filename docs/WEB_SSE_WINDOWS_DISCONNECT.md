# Исправление обрыва Web/SSE на Windows — 1.10.30

## Что изменено

- **Исправлен лишний traceback при отключении клиента.** Если браузер закрыл SSE-подключение во время генерации, Windows может выдавать `ConnectionAbortedError (WinError 10053)`. Теперь этот штатный обрыв перехватывается вместе с `BrokenPipeError` и `ConnectionResetError`; вызывается остановка соответствующего `request_id`.
- **Сохранено существующее поведение потока.** Формат SSE, маршруты, управление сессиями и Web/Telegram не менялись.

## Что ещё не исправлено

- Если GPU/Vulkan возвращает пустой ответ, CPU отвечает слишком долго или модель получает больше своего лимита в 4096 токенов, запрос по-прежнему может зависать. Эти ошибки видны в логах от 7 ноября 2026 года и требуют отдельного исправления ограничений времени, фонового генератора заголовков и бюджетирования контекста.
- `WinError 10053` сам по себе не доказывает первопричину закрытия соединения (браузер, ОС, антивирус либо отмена запроса).

## Проверка

Добавлен статический regression-тест, фиксирующий набор перехватываемых исключений и вызов остановки запроса. Локальные сборки и тесты не выполнялись по требованию владельца. End-to-end поведение на Windows требует отдельного подтверждения.

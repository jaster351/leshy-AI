# 1.10.153 — управление контекстом и восстановление постоянных правил

Дата: 15.11.2026. Исправления после анализа пользовательских логов и повторяющихся проблем 1.10.152.

## Что исправлено

1. Постоянные правила пользователя из `persistent_rule_context` включаются независимо от состояния Mem0 и GraphRAG. Интеллектуальная память дополняет базовую, а не подменяет её.
2. Удалено преждевременное обрезание потокового диалога до 2600 символов. Теперь единственный обязательный бюджет перед генерацией — `apply_context_budget`, рассчитываемый из реально объявленного `n_ctx` backend и резерва ответа.
3. При переполнении приоритет отдан постоянным правилам, текущему запросу, восстановленной теме и подтверждённым результатам инструментов. Из оставшегося бюджета загружается максимально возможная история.
4. Уточнение «ответь на мой первоначальный вопрос» ищет исходный вопрос из этой же сессии, а не ближайшую нерелевантную реплику. История других пользователей не подключается.
5. Новый общий переключатель в Web → Настройки → «Память диалога и контекст модели»: **Авто** или **Вручную**, ползунок 0–100% от «Минимум» до «Безлимит ∞». Сохранение — `LeshyBrain/settings/context.json`. API `GET/POST /v1/context/settings` с проверкой локального доступа либо авторизации владельца.
6. Настройка бюджета применяется к `AdaptiveLLM.chat` и потоковому `AdaptiveLLM.stream_chat`. Следовательно, она влияет на **Web, Telegram, SuperAgent** и другие обращения к общей модели на данном компьютере.

## Что означает регулятор

- **Авто (по умолчанию)**: используется максимальный доступный текущему backend объём контекста и извлекается актуальная часть истории.
- **Вручную, минимум**: минимальный бюджет для недолгого ответа. Из памяти ничего не удаляется, но модель видит меньше деталей одновременно.
- **Вручную, 50%**: промежуточный бюджет между минимумом и настроенным `n_ctx`; количество извлекаемых последних реплик также увеличивается.
- **Вручную, Безлимит ∞**: сохраняется возможность искать по всей истории собственной сессии, включая сообщения вне последних 96 реплик, и загружать релевантные фрагменты. **Это не отменяет конечное контекстное окно LLM** — например, при `n_ctx=4096` за один запрос 4096 токенов плюс резерв для ответа распределяются в рамках этого ограничения. Нельзя обещать буквальное понимание бесконечного текста или полную точность извлечения.
- При длинной истории локальное извлечение сначала выполняет простой текстовый поиск по вопросам пользователя. Для более точного семантического поиска потребуется дальнейшее развитие индекса диалогов, эмбеддингов, проверки цитат и версионированных резюме.

Все режимы **не отключают самообучение, не удаляют Knowledge и не ограничивают рост базы знаний**. ZIP/Zstd можно использовать для без потерь хранения истории отдельно, но архив нельзя непосредственно передать модели как готовый контекст.

## Область действия и ограничения

Настройка действует **на все интерфейсы этого экземпляра Лешего**, включая Web, Telegram и SuperAgent. На каждом компьютере собственный `LeshyBrain/settings/context.json`; синхронизация этого параметра между ПК1 и ПК2 отдельно пока не реализована. Идентичность пользователя и права сессий сохраняются.

Большое число постоянных правил может физически не поместиться одновременно даже в выбранное окно модели. Система старается их сохранить в первую очередь, но не может обещать абсолютное соблюдение всех инструкций или отсутствие галлюцинаций.

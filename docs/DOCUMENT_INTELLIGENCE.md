# Document Intelligence Лешего

`DocumentIntelligence` превращает локальные документы в Markdown, пригодный для диалога, памяти и RAG.

Основной конвертер — MarkItDown. Поддерживаемые установленными extras форматы включают PDF, DOCX, XLSX и PPTX. Для PDF предусмотрен fallback через `pypdf`, а для TXT/MD/CSV/JSON/LOG — встроенное чтение текста.

## Ограничения безопасности

- API принимает только локальный путь; `http://`, `https://` и `ftp://` отклоняются;
- размер файла ограничивается до начала преобразования;
- MarkItDown plugins по умолчанию выключены;
- обработка выполняется с правами процесса Лешего, поэтому Web API требует существующую авторизацию;
- документ не становится доверенным знанием автоматически: дальнейшее сохранение в память/RAG должно проходить обычный pipeline происхождения данных.

## API

`POST /v1/documents/convert`

```json
{"path":"C:/Users/User/Documents/report.docx"}
```

Ответ содержит `markdown`, имя движка, размер и безопасные metadata файла.

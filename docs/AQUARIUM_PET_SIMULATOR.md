# Аквариум Лешего

Модуль создаёт виртуальный аквариум-питомец, который Леший должен воспринимать как модель настоящей живой системы. Рыбы получают голод, стресс, здоровье и возраст; вода меняется со временем; неправильные действия имеют последствия вплоть до гибели.

## Режимы

Поддерживаются два разных режима среды:

- `freshwater` — пресноводный;
- `marine` — морской.

В морском режиме дополнительно учитываются солёность, испарение/автодолив и скиммер. Вид нельзя заселить в среду, для которой источник не подтверждает его пригодность.

## Источники

Основной источник характеристик рыб — FishBase:

- https://www.fishbase.se/
- https://fishbase.ropensci.org/

Для морских таксонов используется дополнительная проверка WoRMS:

- https://www.marinespecies.org/
- https://www.marinespecies.org/rest/

Для будущего расширения на морских беспозвоночных и растения предусмотрен SeaLifeBase:

- https://www.sealifebase.ca/

Профили видов загружаются по требованию и кэшируются в `LeshyBrain/data/aquarium_species_cache.json`. В репозиторий не копируется вся база видов.

## Правило достоверности

Если характеристика вида неизвестна, она остаётся неизвестной. Симулятор не должен превращать отсутствие данных в выдуманный факт.

Каждый профиль содержит:

- научное название;
- среду обитания;
- известные диапазоны температуры, pH и жёсткости;
- максимальный размер;
- минимальный размер социальной группы;
- территориальность и агрессию;
- парное поведение;
- атмосферное дыхание;
- связь с актиниями;
- рацион;
- список источников;
- текстовые свидетельства;
- уровень уверенности.

В код встроен небольшой проверенный кэш для офлайн-старта: `Paracheirodon innesi`, `Betta splendens`, `Amphiprion ocellaris`, `Zebrasoma flavescens`. Все эти записи содержат ссылки на FishBase.

## Поведение

Неон получает дополнительный стресс при слишком маленькой стае. Betta не считается стайной и получает риск внутривидового конфликта при совместном содержании. Клоун учитывает парное поведение и связь с актиниями. Жёлтый хирург учитывает территориальность и травоядность.

Для остальных видов профиль строится из FishBase по научному названию. Текстовые признаки, которые удалось подтвердить, превращаются в параметры симуляции. Неизвестные признаки остаются пустыми.

## Биологическая модель

На каждом шаге меняются:

- температура;
- растворённый кислород;
- аммиак/аммоний;
- нитрит;
- нитрат;
- солёность в морском режиме;
- голод;
- стресс;
- энергия;
- здоровье.

Бионагрузка и остатки корма ухудшают воду. Фильтр преобразует азотистые соединения. Аэрация повышает кислород. Растительная биомасса участвует в модели кислорода и нитрата. Нарушение диапазонов вида увеличивает стресс.

## Решения Лешего

`POST /v1/aquarium/leshy-step` передаёт локальной LLM состояние аквариума. Модель получает инструкцию считать питомца настоящим и не допускать гибели или хронического стресса.

Разрешённые действия ограничены белым списком:

- кормление;
- подмена воды;
- изменение температуры;
- аэрация;
- фильтр;
- освещение;
- скиммер для моря;
- автодолив;
- обслуживание фильтра;
- наблюдение без вмешательства.

LLM обязана вернуть JSON. Неизвестные команды не выполняются.

## Визуализация

В Web UI появляется кнопка `Аквариум Лешего`. Панель показывает анимированный аквариум, каждую рыбу, состояние воды, здоровье/стресс/голод, последнее решение Лешего, журнал событий и источники видовых профилей.

Переключатель `Автопилот` запускает ускоренный эксперимент: Леший принимает решение, затем проходит один виртуальный час. Интервал интерфейса — 5 секунд реального времени.

## API

- `GET /v1/aquarium/state`
- `GET /v1/aquarium/species?scientific_name=Betta%20splendens`
- `POST /v1/aquarium/reset`
- `POST /v1/aquarium/add`
- `POST /v1/aquarium/tick`
- `POST /v1/aquarium/action`
- `POST /v1/aquarium/leshy-step`

Состояние сохраняется в `LeshyBrain/data/aquarium_state.json` и переживает перезапуск.

## Что ещё нужно для научно более точной версии

Следующий этап — подключить актуальные таблицы FishBase через S3/Parquet, а также отдельные таблицы ecology, diet, food items, predators, reproduction, spawning и swimming. Затем добавить пол, возраст, реальную биомассу, индивидуальные территории, болезни, размножение, икру/личинок, пресноводные растения и SeaLifeBase-сущности морского аквариума.

Нужны длительные eval-прогоны на 30/90/365 виртуальных суток. Метрики: смертность, средний стресс, стабильность воды, число опасных действий Лешего и количество аварийных вмешательств.

Эта игровая модель не должна напрямую управлять физическим аквариумом без отдельного fail-safe контроллера и аппаратных ограничений.

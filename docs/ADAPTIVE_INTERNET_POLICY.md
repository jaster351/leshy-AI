# Адаптивный доступ Лешего в интернет и срок жизни знаний — 1.10.85

## Зачем

Локальная LLM отвечает быстро, но её обучающие данные могут заканчиваться
2024 годом. Интернет нужен не на каждый вопрос: важно обращаться к нему при
явном запросе, при быстро меняющейся информации, при пробеле проверенной
базы или истечении срока актуальности **конкретного** знания.

Дату берём из локальных часов ОС каждого компьютера. Неправильные часы
на ПК — отдельная причина неверной оценки свежести.

## Приоритеты принятия решения

1. `/search ...`, «проверь в интернете», «посмотри в сети», «найди ... онлайн»
   и другие явные просьбы всегда инициируют живой поиск. Кэш НЕ вправе отменить
   прямой запрос пользователя.
2. CVE/GHSA и актуальные бюллетени безопасности, новости, версии, погода,
   курсы, цены, расписания и законы требуют свежих данных. Но недавно
   проверенная **trusted**-запись с ещё действующим TTL позволяет обойти
   повторную загрузку при отсутствии явной просьбы перепроверить источник.
3. Для обычных фактических записей базовый TTL — **180 дней**. Если
   относящаяся к вопросу доверенная запись старше него, требуется проверка.
4. Если есть лишь непроверенные `candidate`-знания, они не заменяют интернет.
   Если нет достоверных сведений, фактические информационные вопросы могут
   обращаться к поиску. Для стандартных определений, математики, творчества,
   инструкций и непринципиальных вопросов используются локальная LLM
   и проверенные знания — без ожидания сети.
5. Если LLM признаёт отсутствие данных, обычный непотоковый API
   дополнительно умеет сделать поисковый повтор.
6. При недоступном интернете Леший сообщает об ошибке или недоступности
   проверенных источников, а не сочиняет текущие сведения из знаний LLM.

## Сроки актуальности

| Контекст | TTL |
| --- | --- |
| Курсы, котировки, другие быстро меняющиеся цены | 15 минут |
| Погода | 30 минут |
| Новости | 1 час |
| CVE / бюллетени безопасности | 6 часов |
| Расписания | 6 часов |
| Версии / релизы | 24 часа |
| Законы и нормы | 7 дней |
| Обычные факты | **180 дней** |
| Стабильные физические законы / фундаментальные формулы | До 2 лет |

Это **срок до необходимости повторной проверки**, а не автоматическое
удаление факта. Для записей с собственным TTL применяется более короткий
из двух сроков. Исторические и неизменные факты сохраняются, но их происхождение
и возраст не скрываются.

## Режим самообучения

Переключатель «Самообучение» управляет фоновым изучением и записью
полученных сведений в LeshyBrain, **не доступом к сети** для ответа на
обычный или явный запрос. При включённом обучении найденные материалы
попадают в базу как `candidate`, а не автоматически становятся проверенными.
Обновление базы знаний не переобучает веса Qwen/GGUF и не сдвигает дату
весов LLM. Для этого используется база знаний, проверка и retrieval.

Данные с ПК №1 могут реплицироваться на ПК №2 после доверенного сопряжения,
но полученные записи остаются `candidate` до собственной проверки.

## Диагностика

В журнале появляется `internet_route_decided` с причиной, TTL, количеством
релевантных trusted/candidate и решением `online`. В динамической консоли
появляется последний маршрут: «поиск» или «локально».

Для поиска дополнительно должны появиться `live_search_started` и
`live_search_finished`. При ошибке сетевого запроса смотрите
тип исключения и причины в журнале. SSL/TLS-ошибка
`CERTIFICATE_VERIFY_FAILED` требует правильных сертификатов Windows/Python
или доверенного сертификата прокси; **нельзя** выключать TLS-верификацию.

## Критерии проверки после Windows-сборки

- «Напиши новый поздравительный текст» — локально, без live-search.
- «Что такое закон Ома?» — локальный быстрый ответ.
- «Проверь в интернете CVE-2026-119977» — всегда веб-поиск.
- «Какая актуальная версия Python?» — веб, если нет verified/trusted
  записи в пределах суток; повтор в пределах TTL может обойти сеть.
- Факт из LeshyBrain возрастом 181 день по обычной теме — веб-проверка.
- Недоверенная или неотносящаяся к вопросу запись не подавляет интернет.
- При включённом обучении принятые сведения остаются кандидатами с URL.
- На ПК №2 ошибка HTTPS, если она сохраняется, должна быть видимой:
  новый роутер не заменяет исправление сетевого доверия.

Код проверен статически; полная проверка в Windows и CI остаётся отдельным
условием приёмки. Не запускать CI, сборки и тесты автоматически без
соответствующего разрешения владельца.

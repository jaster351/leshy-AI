# Защита Browser Agent: прямые IP-адреса

Статус: исправление защиты прямых IP уже внедрено более полным PR #91; этот PR добавляет документацию и регрессионные проверки. E2E ещё не подтверждён.

При пустом `allowed_hosts` браузерный агент теперь отклоняет прямые IPv4/IPv6-адреса, которые Python `ipaddress` считает не глобальными. Это включает loopback, RFC1918, link-local, ULA и другие специальные диапазоны. Явное точное совпадение адреса с `allowed_hosts` сохраняет административно разрешённый доступ к локальным сервисам. Проверки схемы, порта и учётных данных URL сохранены.

**Ограничение:** это не полная SSRF-защита. DNS-имена могут разрешаться во внутренние адреса, а HTTP-перенаправления могут менять назначение. Нужны проверка всех DNS A/AAAA при соединении, защита от rebinding, контроль фактического peer IP и каждого redirect, в том числе внутри browser-use/Playwright. Пока это не сделано, браузерный агент нельзя считать защищённым от SSRF.

Добавлены регрессионные тесты на прямые IPv4/IPv6, явное разрешение loopback и публичный HTTPS IP. По правилу проекта локальные тесты и сборки не запускались. Перед слиянием необходимы статический read-back, проверка CI и всех runtime-маршрутов.

# Интернет-погода Лешего — 1.10.84

Исправлено получение погоды без участия локальной языковой модели: значения температуры и условия берутся только из внешних HTTPS-источников.

- Основной источник для указанного города — Open-Meteo (геокодирование и прогноз).
- При сетевой ошибке Open-Meteo используется резервный JSON-источник wttr.in.
- Если город не указан и переменная `LESHY_WEATHER_CITY` не задана, wttr.in определяет **приблизительный** город по публичному IP. При VPN/прокси геолокация может быть неверной. Для точной привязки задайте `LESHY_WEATHER_CITY` или явно напишите город.
- Распознаются запросы «Погода в Челябинске», «Погода Челябинск», «Погода завтра в Москве», «Какая погода сейчас?», «Температура на улице?».
- В Web, API и Telegram добавлена ссылка на фактически использованный источник.
- Для HTTPS с корпоративным прокси можно установить `LESHY_WEATHER_CA_BUNDLE=C:\\certs\\trusted-ca.pem` (доверенный PEM, установленный администратором). Проверка сертификатов не отключается.
- При ошибке двух источников возвращается понятное сообщение без вымышленных погодных цифр, в журнал заносится событие `weather_provider_failed` с названием провайдера и типом ошибки, без URL с параметрами и секретов.

## Проверить вручную на локально собранной версии

1. Спросить «Какая погода в Челябинске сегодня?» — получить прогноз и ссылку Open-Meteo.
2. Спросить «Какая погода завтра в Москве?» — получить завтрашний прогноз.
3. Без `LESHY_WEATHER_CITY` спросить «Какая погода сейчас?» — получить город по IP либо честную ошибку, без придуманной температуры.
4. Проверить те же вопросы через Web и Telegram. При блокировке Open-Meteo — переход на wttr.in и отображение его источника.
5. Если оба сервиса не работают, посмотреть `weather_provider_failed` в логах; при ошибке TLS проверить доверенные сертификаты.

Сборка и автотесты при внесении этого изменения **не запускались**: проверка остаётся за локальным экземпляром пользователя.

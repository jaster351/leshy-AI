# Локальное изучение документов

Контур human learning получает локальный слой извлечения текста без обязательных облачных API.

Поддерживаемые форматы адаптера: `.txt`, `.md`, `.pdf`, `.docx`, `.pptx`. Текстовые файлы читаются стандартной библиотекой Python. Для PDF используется опциональный `pypdf`, для DOCX — `python-docx`, для PPTX — `python-pptx`. Импорт выполняется лениво: отсутствие одной опциональной зависимости не должно мешать запуску Лешего или обработке других форматов.

Адаптер ограничивает объём извлечённого текста двумя миллионами символов. Неизвестные форматы отклоняются явно. Пустой результат также не считается успешно изученным документом: для сканированного PDF или изображения требуется отдельный OCR/vision-контур.

Модуль: `src/leshy/document_learning.py`. Следующий этап интеграции — подключить `extract_document()` к `MaterialLearningWorker`, после чего извлечённый текст должен идти в существующий pipeline candidate → verification → trusted с сохранением provenance исходного файла. OCR остаётся отдельным этапом и не должен подменяться догадками модели.

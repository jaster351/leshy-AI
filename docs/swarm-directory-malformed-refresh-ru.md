# Повреждённый ответ каталога swarm

При обновлении публичного каталога различаются два случая:

- Корректный пустой список `[]` при отсутствии ошибки каталога означает явное удаление всех seed-адресов оператором. Ранее известные адреса удаляются.
- Некорректный тип ответа (`null`, число, строка, объект) **не** считается отзывом адресов: сохраняются последние проверенные seed-адреса, выставляется `invalid_directory_payload`, ошибка фиксируется в диагностике.

Неправильные отдельные элементы списка по-прежнему отбрасываются валидатором. Это не подтверждает подлинность каталога или работоспособность публичной сети. Regression: `tests/test_swarm_malformed_directory_refresh.py`; тесты не запускались по требованию владельца. Перед интеграцией нужны статическая проверка всего runtime-маршрута, внешний CI и end-to-end проверка.

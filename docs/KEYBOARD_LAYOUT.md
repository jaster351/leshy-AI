# Исправление случайно выбранной раскладки

Леший распознаёт отдельные короткие сообщения, которые выглядят как русский текст, набранный на английской клавиатуре (или наоборот). Например, `ghbdtn` → «привет», `rfr ltkf` → «как дела». Он должен начать ответ с «Похоже, вы имели в виду: ...», затем продолжить по смыслу. Исходное сообщение остаётся неизменным в истории и не переписывается в базе.

Алгоритм намеренно консервативный: применяется только при достаточном совпадении с небольшим словарём естественных слов. URL, пути, команды, адреса, код, числовые и смешанные строки не преобразуются. Подсказка добавляется в контекст обычного `LeshyApp.chat` и потокового `RealtimeChat` (Web/Telegram). Отдельные ранние маршруты, например фактологические инструменты и автономные задания, пока не используют эту подсказку. Модель может не соблюсти формулировку дословно — это не гарантированный постпроцессор.

Проверки: добавлены сценарии приветствия, вопроса, корректного русского текста, технических строк и контекстной подсказки. Runtime, локальные unit-тесты, Windows, Web и Telegram E2E не запускались. Для подтверждения полного поведения нужны доступный CI и сквозные проверки.

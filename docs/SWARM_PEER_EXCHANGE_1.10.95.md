# Рой Лешего: прямой обмен адресами соседей (1.10.95)

## Что реализовано

GitHub — только каталог первоначальных адресов, не рабочий сервер.
После знакомства компьютеры общаются по HTTPS напрямую с добровольными публично доступными участниками.

В подписанном запросе приветствия узел может объявить добровольно настроенный публичный HTTPS-адрес.
Он не публикуется автоматически: требуется отдельная переменная окружения LESHY_SWARM_PUBLIC_ENDPOINT.
Без неё Леший остаётся исходящим клиентом, а его домашний IP/порт не публикуются в списке соседей.

При регистрации добровольный узел возвращает ограниченный список других доступных участников
(публичный адрес и ключевой ID, без сообщений, памяти и личных данных).
Получатель сохраняет до 64 адресов локально в LeshyBrain/cluster/swarm-peers.json
с TTL 6 часов, по отказу одного адреса пробует другие без GitHub.
Отключённые и просроченные адреса постепенно исключаются.
Чтение GitHub происходит только когда нет успешного пути и нужна повторная загрузка
первоначальных адресов, не чаще одного раза в 15 минут.

Счётчик обнаруженных публичных peer доступен по GET /v1/swarm/status.
Публичный каталог остаётся пустым до появления реально работающего добровольного
HTTPS-узла с общедоступным адресом. Нельзя установить контакт с полностью
неизвестными компьютерами, если изначально нет ни одного доступного адреса.

## Что всё ещё НЕ реализовано

Это пока обмен адресами поверх HTTPS, а НЕ полнофункциональный P2P.
Машины за NAT нельзя автоматически сделать доступными извне: необходимы
hole punching/relay с устойчивыми исходящими соединениями.
Объявленные другими адреса — непроверенные подсказки: до исполнения задач
необходима проверка владения адресом (challenge-response) и доверенный
сквозной транспорт. Без этого никакие вычисления на чужой машине не разрешены.
Глобальная DHT/gossip, распределение вычислений, проверяемая общая база
знаний и арбитр единственного ответа пока не реализованы.
Существующий обмен LAN знаний не превращён в мировую синхронизацию.

Секреты, переписки, персональная память и файлы пользователя не выходят
в сеть автоматически. Предоставление CPU/GPU чужим пользователям остаётся
выключенным. Регистрация в рое и разрешение обрабатывать чужие задачи —
разные настройки. Пилотный rendezvous слушает только loopback; добровольный
узел должен отдельно настроить HTTPS reverse proxy, ограничения соединений,
проверку сертификатов и защиту от DoS. Не выставляйте основной
административный Web UI Лешего напрямую в интернет.

В GitHub отсутствуют реестр подключённых пользователей, операции публикации
онлайн-статуса, сообщения, знания и результаты вычислений.
Для этих целей будущая сеть использует собственный обмен и репликацию.

Локальные автотесты предусмотрены в tests/test_swarm_peer_exchange.py.
Сборка и тесты не запускались; до готового публичного роя ещё необходима проверка на реальных узлах.

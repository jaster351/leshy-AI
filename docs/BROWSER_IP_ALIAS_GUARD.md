# Защита Browser Agent от IP-алиасов (частичная)

Проверка `BrowserAgent._host_allowed()` теперь отклоняет прямые неглобальные IPv4/IPv6 и браузерные числовые варианты IPv4 (десятичный DWORD, шестнадцатеричный, восьмеричный, сокращённый). Это происходит до передачи действия адаптеру. Исключения допускаются только по **точному** написанию хоста в `allowed_hosts`; разрешение `127.0.0.1` не разрешает автоматически `127.1`.

## Границы и остаточный риск

Это **не полная защита от SSRF**. DNS-имена могут резолвиться во внутренний адрес, а браузер может перейти по redirect или выполнить дополнительные запросы. Требуется контроль фактического peer IP, DNS/rebinding, каждого redirect и субресурсов непосредственно в браузерном адаптере. До такого контроля недоверенные URL следует открывать в сетево изолированном браузере с egress ACL.

Новые тесты проверяют прямые IP и алиасы без реального HTTP. Локальные тесты и сборки не запускались по требованию владельца. Изменение не подтверждено end-to-end и не должно маркироваться как полноценная SSRF-защита.

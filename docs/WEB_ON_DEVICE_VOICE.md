# Локальное распознавание речи в браузере

Адаптер `web/voice-on-device.js` — отдельная реализация для интеграции с #307 и #308. В объединённом кандидате подключён к контроллеру и панели разговора. До реальной приёмки не является подтверждённым пользовательским режимом.

- Только доверенный HTTPS (или localhost). Никаких исключений для удалённого HTTP.
- После нажатия микрофона вызвать `leshyOnDeviceVoice.prepare({language, signal, onStatus})`. Статусы checking/downloading/ready отражать в существующем UI. У браузерного API нет байтового прогресса; не имитировать проценты, скорость и ETA. Нативное окно зависит от браузера.
- При ready вызвать `start({language, signal, onText, onStatus, continuous})`. Передавать тот же AbortSignal текущей сессии, отменять при смене чата, остановке, закрытии страницы. `onText` содержит отдельно окончательную и промежуточную части. Считать успешным только завершившийся `done`; перед отправкой проверить актуальность epoch/session. `stop()` завершает реплику, `abort()` не отправляет её. Диктовка не отправляет сообщение автоматически.
- На unavailable/unsupported/not-installed/prepare-error предложить существующий серверный ASR, явно указав передачу аудио своему серверу Лешего. Не переключать `processLocally` в false, не обращаться к облачному распознаванию. Отмена или отказ разрешения не должны начинать запись другим методом.
- Системное скачивание пакета может продолжиться после отмены ожидания; приложение больше не запускает микрофон для отменённой сессии.
- Удалённая голосовая связь зависит от доверенного TLS #308 и действующего авторизованного ASR/TTS #307. Web Speech не заменяет HTTPS.
- В Android отдельно проверить системный on-device recognizer и наличие русского языка; этот JS не является Android-интеграцией.

Приёмка: localhost и доверенный LAN/домен HTTPS, HTTP с удалённого IP, нет API, русский пакет available/downloadable/downloading/unavailable, отказ загрузки, отмена во время загрузки, отказ/отзыв микрофона, смена сессии, stop/abort, отсутствие облачных запросов, серверный резервный режим с явным выбором, озвучка и повторная реплика. До отдельного разрешения сборки/автотесты/CI не запускать.

Источник API: https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API

Панель в чате показывает историю измеренного RMS микрофона, а не имитацию голоса. Серверный вариант запускается отдельной кнопкой с предупреждением о передаче аудио; при ошибке диктовки выбор сохраняет режим диктовки. Системное окно загрузки зависит от браузера. Нативный Android не изменён.

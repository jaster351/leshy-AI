# Локальный профиль сотрудника технической поддержки

Открытый репозиторий содержит только универсальный стиль ответов и технические принципы. Названия работодателей, корпоративные тарифы, внутренние инструкции и клиентские данные в репозиторий не добавлять.

Черновик: /support <текст вопроса клиента>. Леший даёт один естественный ответ от лица техподдержки. Без автоматической отправки.

Если нужны частные инструкции, создайте только на своём компьютере зашифрованный файл LeshyBrain/private/support_profile.enc. Код поддерживает Fernet (cryptography уже есть в зависимостях). Ключ LESHY_SUPPORT_PROFILE_KEY храните отдельно от публичного Git, лучше в защищённом локальном хранилище. Пример содержимого JSON до шифрования: {"facts":[{"cues":["скорость","канал"],"text":"Уточнить условия по текущему договору."}]}. При отсутствии ключа или файла применяется общий стиль без догадок.

Переименование текущих файлов не убирает ранее опубликованные сведения из истории Git. Для полноценного удаления требуется отдельно защитить репозиторий и очистить историю.

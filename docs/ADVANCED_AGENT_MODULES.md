# Интеллектуальная память, GraphRAG и команда подагентов

Новые модули развивают Лешего по тем же открытым архитектурным направлениям, которые используются в Mem0, GraphRAG, LangGraph и Deep Agents, но не копируют их закрытые данные и не требуют внешнего облачного сервиса.

## Интеллектуальная память

Модуль `intelligent-memory` работает поверх существующего `LeshyBrain` и таблицы `memories`.

Вместо передачи в каждый ответ первых попавшихся записей память ранжируется по:

- совпадению с текущим запросом;
- важности записи;
- свежести;
- точному совпадению фразы.

Леший может автоматически сохранять явно сформулированные долговременные предпочтения пользователя, например «я предпочитаю…», «мне нравится…», «я использую…». Автоматическое сохранение блокируется для сообщений, похожих на пароль, токен, CVV, SMS-код, приватный ключ и другие секреты.

Ручное `/remember ...` продолжает работать как раньше.

Дополнительная команда:

```text
/memory запрос
```

Она показывает наиболее релевантные записи памяти для текущего пользователя.

## Knowledge Graph / GraphRAG

Модуль `knowledge-graph` строит локальный граф из:

- проверенных (`trusted`) знаний Лешего;
- долговременной памяти конкретного пользователя;
- концептов, которые встречаются в этих фактах.

Факт и пользовательская память являются узлами. Концепты связываются с ними рёбрами `mentions`. При запросе Леший получает не только прямые совпадения, но и связанные факты через общие концепты.

Граф хранится в том же SQLite-хранилище LeshyBrain и не требует Neo4j, облака или платной БД.

Дополнительная команда:

```text
/graph запрос
```

Она выводит связанные факты GraphRAG.

## Оркестратор подагентов

Модуль `agent-orchestrator` реализует отдельные роли:

- Исследователь — проверяет фактическую сторону и пробелы;
- Архитектор — строит решение и зависимости;
- Критик — ищет ошибки, риски и противоречия;
- Оптимизатор — ищет более эффективный и параллельный вариант.

После этого origin-узел Лешего собирает один итоговый ответ. Внутренние рассуждения подагентов пользователю не раскрываются — используются только их рабочие выводы.

Запуск вручную:

```text
/agents подробная задача
```

Также распознаются естественные команды вроде «используй команду агентов» или «проанализируй несколькими агентами».

Если активен `distributed-cluster` и обнаружено два или больше компьютеров, роли назначаются разным узлам и выполняются параллельно. При одном компьютере они выполняются последовательно, чтобы несколько запросов не боролись за один локальный inference-slot.

## Переключение

Все три модуля отображаются в `Настройки → Модули` и могут быть отключены независимо. Переключение не удаляет память и граф с диска — оно только включает или выключает использование соответствующего слоя в runtime.

# Голосовой интерфейс

Во всех UI Лешего с доступом к микрофону должны поддерживаться wake-фразы «Привет, Леший», «Слушай, Лёша», «Слушай, Леший», «Окей, Лёша», «Окей, Леший».

В настройках голоса обязателен явный блок «Пол голоса» с двумя кнопками/переключателями: «Мужской» и «Женский». Ниже пользователь выбирает конкретный голос/тембр и может нажать «Прослушать пример» до сохранения.

Отдельно настраиваются: голосовая активация, звуковое подтверждение, визуальная реакция, короткий голосовой ответ после wake-word, чувствительность распознавания и выбранный голосовой профиль. Настройки сохраняются между перезапусками и применяются к Web, Windows/desktop, mobile/tablet и будущим клиентам.

## Голосовые сообщения Telegram

Telegram-бот принимает нативные голосовые сообщения (OGG/Opus), скачивает их через Telegram Bot API и распознаёт локальным `faster-whisper`. Полученный текст передаётся в обычный/потоковый чат с сохранением ID пользователя и сессии. Ответ отправляется текстом, в ответ на исходное голосовое.

- В личном чате голосовые разрешены только пользователям с доступом к боту.
- В группах голосовые обрабатываются только при явном обращении (например, ответе на сообщение Лешего), без автоматического прослушивания всех записей.
- Ограничения: длительность до 5 минут, файл до 20 МБ. Для повреждённых или нераспознанных записей бот возвращает понятное сообщение, не вызывая LLM.
- Telegram и веб-интерфейс используют один экземпляр ASR и общий ограничитель параллельных запросов.
- Для первой установки faster-whisper модели может потребоваться интернет. После загрузки распознавание выполняется локально, без платных speech API. Передача самого голосового сообщения через Telegram требует связи с серверами Telegram.

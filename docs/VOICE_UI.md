# Голосовой интерфейс

Во всех UI Лешего с доступом к микрофону должны поддерживаться wake-фразы «Привет, Леший», «Слушай, Лёша», «Слушай, Леший», «Окей, Лёша», «Окей, Леший».

В настройках голоса обязателен явный блок «Пол голоса» с двумя кнопками/переключателями: «Мужской» и «Женский». Ниже пользователь выбирает конкретный голос/тембр и может нажать «Прослушать пример» до сохранения.

Отдельно настраиваются: голосовая активация, звуковое подтверждение, визуальная реакция, короткий голосовой ответ после wake-word, чувствительность распознавания и выбранный голосовой профиль. Настройки сохраняются между перезапусками и применяются к Web, Windows/desktop, mobile/tablet и будущим клиентам.

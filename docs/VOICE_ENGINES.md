# Голосовые движки Лешего

## Назначение

Настройки голоса доступны в Web UI: нижнее меню **«Леший» → «Настройки» → «Голос Лешего»**.

Пользователь может выбрать:

- пол персонажа: мужской или женский;
- голосовой движок;
- конкретный голос;
- характер подачи;
- темп речи.

Выбор сохраняется локально в `LeshyBrain/Settings/voice.json` и не должен сбрасываться после обновления или перезапуска.

## Движки

### Авто

Леший выбирает лучший уже доступный локальный движок. Если Piper установлен и нужный голос загружен, используется Piper. Иначе используется системный TTS Windows.

### Piper

Основной рекомендуемый нейросетевой локальный TTS. Runtime и голосовые модели хранятся в `LeshyBrain/voice/` и после загрузки работают без интернета.

Для русского языка в интерфейсе предусмотрены мужские голоса `denis`, `dmitri`, `ruslan` и женский `irina`.

Кнопка **«Скачать / подключить»** загружает runtime Piper и выбранную модель голоса.

### Windows System Speech

Использует штатный `System.Speech`/SAPI. Ничего дополнительно скачивать не требуется. При отсутствии явно выбранного голоса Леший пытается подобрать голос нужного пола и русского языка.

### RHVoice

Открытый синтезатор речи. На Windows Леший использует установленный RHVoice через SAPI. Лицензия самого движка и лицензии отдельных голосовых пакетов могут отличаться, поэтому перед распространением конкретного голоса необходимо учитывать его собственную лицензию.

### eSpeak NG

Лёгкий открытый резервный синтезатор. Звучит менее естественно, зато потребляет мало ресурсов. В Windows кнопка подключения может скачать официальный MSI и запустить установщик.

## Киношные профили

Встроенные профили не являются копиями голосов конкретных актёров или персонажей. Они задают только общий характер подачи:

- Естественный;
- Киногерой — уверенный;
- Нуар — спокойный;
- Андроид — ровный;
- Кинозлодей — более медленный;
- Рассказчик — выразительный.

В будущем допускаются дополнительные пользовательские голосовые пакеты, если у пользователя есть необходимые права на исходный голос и модель.

## Производительность

TTS не держится постоянно в памяти и запускается только во время озвучивания готового ответа. Голосовой движок не должен получать LLM inference-slot и не должен ухудшать эталонную скорость текстового ответа, зафиксированную в контрольной точке `checkpoint/1.10.40-fast-baseline`.

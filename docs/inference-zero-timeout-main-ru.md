# Неблокирующий inference-слот

База main: 9957e4e2e4da97b6d553c2f5b072cdae7f197b8f (11.11.2026).

В InferenceScheduler.acquire() сначала проверяется отмена, затем возможность немедленно выдать свободный слот и только после этого deadline. При timeout=0 свободный слот доступен; занятый приводит к TimeoutError; предварительная отмена приводит к InterruptedError.

Добавлены три регрессионных сценария. Тесты и локальная сборка не запускались по требованию владельца. Изменение не реализует прерывание уже выполняющегося backend. До интеграции в main это не релиз.

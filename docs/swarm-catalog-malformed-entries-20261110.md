# Каталог публичного роя: некорректные записи

При обновлении каталога bootstrap-серверов **явный пустой список `[]`** означает отзыв всех адресов оператором. Список, содержащий только повреждённые URL или элементы неподдерживаемого типа, не является подтверждённым отзывом: прежние проверенные адреса сохраняются до следующего обновления. Ошибка фиксируется как `invalid_directory_entries`.

Если в списке есть хотя бы один допустимый адрес, используется только проверенное подмножество; старые адреса заменяются. Неизвестный тип всего ответа обрабатывается отдельно (`invalid_directory_payload`).

Регрессионные сценарии находятся в `tests/test_swarm_catalog_entries_regression.py`. Локальные тесты и сборки не запускались. Изменение в PR не означает готовность runtime: требуется согласование с параллельными PR и end-to-end проверка перед включением в `main`.

# «Лента» на Windows 11: существующая авторизация и CDP

Сценарий: сообщение из Telegram «https://lenta.com/ зайди в мой профиль и добавь в корзину самое дешёвое мороженое».

## Причина исправленной ошибки

Chromium (Edge/Chrome) не позволяет одновременно открывать один `--user-data-dir` из двух процессов. Раньше «Леший» открывал окно входа, затем Browser Use пытался стартовать **второй** браузер с тем же профилем: `Browser process ... exited before CDP became available`.

Новый сценарий: окно входа открывается с `--remote-debugging-port=0` и `--remote-debugging-address=127.0.0.1`; `BrowserUseAdapter` проверяет `DevToolsActivePort` и подключается к **этому же** окну через локальный CDP. При занятом профиле без CDP агент сообщает о необходимости закрыть только окно отдельного профиля «Ленты» и открыть его заново. Он не копирует cookies в другой профиль и не удаляет файлы блокировки. Обычные окна Edge трогать не надо.

CDP слушает localhost и предоставляет полный доступ к авторизованным вкладкам; не выставляйте порт наружу.

## Что делать на Windows 11

1. Обновить локальный Леший до версии, включающей данное исправление, и перезапустить.
2. В Telegram сказать: «Леший, войти в Ленту». Войти в открывшееся отдельное окно Edge/Chrome через сайт.
3. Ответить в тот же диалог: «готово». **Окно Ленты в новой версии можно оставлять открытым:** агент подключится к нему через CDP.
4. Повторить: «Леший, на lenta.com добавь в мою корзину одну штуку самого дешёвого мороженого». Уточнение магазина/региона производится по сайту; цены и наличие нельзя выдумывать. Финальное оформление и оплата не запускаются.

Если окно авторизации открыто **в старой версии**, без CDP, закройте только окно этого отдельного профиля; затем выполните шаги 2–4. Данные профиля сохраняются.

## Почему веб и Telegram видят разные профили

Веб-интерфейс пока использует `web:local`, Telegram — `telegram:<telegram-user-id>`. Для защиты разных пользователей профили изолированы по владельцу. Авторизация в одном интерфейсе **не доказывает**, что этот же человек владеет другим. Поэтому автоматически объединять cookie, память или историю чатов нельзя; потребуется отдельное подтверждённое связывание аккаунтов. Данная правка исправляет Windows CDP и распознавание команды корзины, **не выдаёт механизм синхронизации аккаунтов за готовый**.

Для Linux без GUI — отдельный headless-режим из другой ветки, он не является причиной этой Windows-ошибки.

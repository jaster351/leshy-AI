# Обновление каталога и отзыв bootstrap-серверов

В режиме публичного подключения каталог GitHub проверяется не реже чем раз в 15 минут при работающем цикле membership, в том числе когда текущий сервер успешно отвечает. Запрос к каталогу не передаёт личность узла и пользовательские данные.

При успешном ответе допустимый ранее выбранный сервер сохраняется; удалённый из каталога адрес заменяется на разрешённый. Явный пустой каталог `[]` означает отзыв всех адресов и запрещает использование ранее сохранённых peer hints как обходного маршрута. Повреждённый ответ, ошибка загрузки или полностью недопустимый непустой каталог не считаются отзывом: ранее проверенные адреса сохраняются.

Ручной `LESHY_SWARM_BOOTSTRAP_URL` не управляется публичным каталогом. Регрессионные сценарии описаны в `tests/test_swarm_catalog_revocation_regression.py`; они добавлены, но локально не запускались. Перед интеграцией необходимы ревью, CI и проверка runtime, в том числе поведения при длительной недоступности GitHub.

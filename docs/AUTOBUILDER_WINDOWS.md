# AutoBuilder Лешего для Windows

AutoBuilder теперь работает как отдельная панель управления Windows для локальной рабочей копии:

```text
C:\Users\JASTER\Documents\GitHub\leshy-AI\dist\Leshy
```

Главное правило: каталог `dist\Leshy\LeshyBrain` является пользовательскими данными и при обновлении программы не удаляется и не заменяется.

## Режимы обновления

### Автообновление репозитория

Фоновая проверка только обновляет локальный `main` через безопасный `git pull --ff-only`. Запущенный Леший при этом не закрывается, сборка не начинается и рабочие файлы `dist\Leshy` не заменяются.

Полученные изменения ждут следующего полного обновления или следующего запуска AutoBuilder.

### Кнопка «Обновить сейчас»

Полный цикл выполняется автоматически:

1. Обновить `main`.
2. Остановить только процесс `dist\Leshy\Leshy.exe`.
3. Запустить штатную сборку и тесты.
4. Подготовить новую программную часть во временном каталоге `.autobuild`.
5. Создать резервную копию предыдущих программных файлов.
6. Заменить программную часть `dist\Leshy`, сохранив `dist\Leshy\LeshyBrain` без изменений.
7. Если замена не удалась — восстановить старые программные файлы.
8. Запустить Лешего снова.

Если сама сборка не прошла, рабочая версия `dist\Leshy` не заменяется и AutoBuilder пытается снова запустить предыдущую версию.

### Полная сборка по таймеру

В интерфейсе можно включить периодическую полную сборку и задать интервал в минутах. По таймеру выполняется тот же безопасный цикл, что и по кнопке «Обновить сейчас».

## Первый запуск AutoBuilder

При запуске панели AutoBuilder:

1. Обновляет локальный `main`.
2. Сравнивает commit репозитория с commit, развернутым в `dist\Leshy`.
3. Если рабочая копия отсутствует или устарела — выполняет полную сборку и безопасное обновление.
4. Запускает `dist\Leshy\Leshy.exe`.

Таким образом, фоновое автообновление может заранее получить изменения, а применятся они при следующем перезапуске AutoBuilder/полном обновлении.

## Интерфейс

Запуск из корня репозитория:

```cmd
windows\autobuilder.cmd
```

В панели доступны:

- состояние репозитория;
- состояние запущенного Лешего;
- версия и commit рабочей сборки;
- кнопка полного обновления;
- кнопка только обновления репозитория;
- запуск и остановка Лешего;
- интервал фоновой проверки репозитория;
- периодическая полная сборка по таймеру;
- журнал AutoBuilder;
- работа через системный трей.

Закрытие окна сворачивает AutoBuilder в трей, а не завершает его.

## Автозапуск

Для совместимости остаётся команда:

```powershell
.\windows\autobuilder.ps1 -Mode install
```

Она регистрирует панель AutoBuilder в пользовательской автозагрузке без необходимости административных прав и запускает интерфейс.

Старый `-Mode watch` теперь является совместимым входом и запускает новую панель в свёрнутом режиме. Это нужно для компьютеров, где ранее уже был установлен старый AutoBuilder.

## Ручная полная сборка без интерфейса

```powershell
.\windows\autobuilder.ps1 -Mode once
```

## Состояние из консоли

```powershell
.\windows\autobuilder.ps1 -Mode status
```

## Удаление автозапуска

```powershell
.\windows\autobuilder.ps1 -Mode uninstall
```

## Безопасность

AutoBuilder не выполняет `reset --hard`, `git clean`, автоматический merge или rebase. При наличии локальных незакоммиченных изменений обновление останавливается.

Программная сборка создаётся в `.autobuild\package-dist\Leshy`, поэтому PyInstaller не удаляет рабочий `dist\Leshy\LeshyBrain`.

Диагностические логи локальной сборки продолжают санитизироваться и публиковаться отдельным контуром диагностики, как было согласовано ранее.

# AutoBuilder Лешего для Windows

AutoBuilder следит за `origin/main` канонического репозитория Лешего и автоматически собирает новый Windows-установщик после появления изменений.

## Что он делает

1. Каждые 60 секунд выполняет безопасный `git fetch origin main`.
2. Если `origin/main` изменился, ждёт короткую паузу стабилизации, чтобы не собирать каждый промежуточный commit из серии.
3. Никогда не перезаписывает локальные изменения пользователя.
4. Обновляет локальный `main` только через `git pull --ff-only` — без автоматического merge/rebase.
5. Запускает штатный `windows/build.ps1`, то есть все unit/smoke проверки выполняются как при ручной сборке.
6. При успехе оставляет актуальный установщик в `dist/` и сохраняет дополнительную копию в `.autobuild/releases/` с SHA commit.
7. Ведёт журналы в `.autobuild/logs/` и краткое состояние в `.autobuild/STATUS.txt`.
8. При ошибке сохраняет лог и повторяет сборку того же commit не чаще чем раз в 5 минут. Новый commit проверяется сразу.
9. Не запускает одновременно два экземпляра наблюдателя.

AutoBuilder отслеживает весь `main`, поэтому подхватывает изменения, которые в канонический репозиторий отправляет ChatGPT/автономный агент, а также любые другие подтверждённые изменения `main`.

## Установить постоянное наблюдение

Из корня репозитория:

```powershell
.\windows\autobuilder.ps1 -Mode install
```

Будет создана задача Windows `Leshy AutoBuilder`, которая запускается при входе пользователя в Windows. После установки задача запускается сразу.

## Проверить состояние

```powershell
.\windows\autobuilder.ps1 -Mode status
```

Также можно открыть:

```text
.autobuild\STATUS.txt
```

## Один раз проверить обновления и собрать

```powershell
.\windows\autobuilder.ps1 -Mode once
```

## Запустить наблюдение в текущем окне

```powershell
.\windows\autobuilder.ps1 -Mode watch
```

или:

```cmd
windows\autobuilder.cmd watch
```

## Удалить автозапуск

```powershell
.\windows\autobuilder.ps1 -Mode uninstall
```

## Безопасность локального дерева

Если в репозитории есть незакоммиченные или неотслеживаемые пользовательские файлы, AutoBuilder останавливает обновление и пишет `PAUSED` в `.autobuild/STATUS.txt`. Он не делает `reset --hard`, `clean`, автоматический merge или rebase.

Артефакты локальной сборки (`dist/`, `build/`, `.autobuild/`, `LeshyBrain/`) исключены через `.gitignore`, поэтому собственные результаты сборки не блокируют последующие обновления.

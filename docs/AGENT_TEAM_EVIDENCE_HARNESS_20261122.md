# Леший: собственный контур анализа и проверки команды агентов

Основа: ветка main 1.10.199. Новый код является самостоятельной реализацией архитектурных идей, а не копией Claude Code, сторонних хуков, MCP-плагинов или чужих промптов.

## Интеграция

- `MultiAgentOrchestrator` остаётся единственным исполнителем команды `/agents`.
- `agent_team_review.py` не вызывает LLM, сеть или инструменты и не хранит секреты. Он только проверяет полноту роли и ограничивает непроверенные отчёты до этапа синтеза.
- Разделяются отсутствие роли, ошибка роли, дубли, усечение отчёта и переполнение контекста.
- Контекст памяти владельца извлекается один раз; каждая роль получает только ограниченную порцию. Системные инструкции ролей сохраняются.
- Итоговая модель получает JSON-данные, явно отмеченные как недоверенные результаты других моделей. Они не становятся системными инструкциями.
- Реальные изменения файлов, успешные тесты и публикация не подтверждаются текстом агентов. Для этого остаются квитанции существующего `Cognitive Core` и инструменты исполнения.
- Для внешних действий ответ содержит определённую кодом отметку об отсутствии доказательств исполнения.
- Структурная полнота ролей не заявляется как независимая проверка фактов.

## Почему это нужно

Владелец хочет, чтобы Леший понимал связные поручения и действовал через свой интеллект, а не через список фраз-триггеров. Новая логика не подменяет понимание: формулировка проходит через LLM-подагентов. Вынесены лишь границы полномочий и корректности отображения результатов.

## Проверка

- Добавлены автономные тесты для недостающих/сбойных/дублирующихся ролей, попытки инъекции, длинного контекста, сохранения исходной задачи и неподтверждённых операций.
- Существующие тесты распределения ролей между физическими узлами не заменяются.
- Python-тесты в этой сессии **не были исполнены**: локальная среда не смогла разрешить github.com для клонирования исходников. Нельзя выдавать добавленные тесты за пройденные.
- Текущий CI до 2026-12-01 запускается вручную; триггеры не менялись.
- Код не трогает RDP-цепочку черновых PR, не меняет модель, версии инструментов или Конституцию Федерации Леших.

## Следующий критерий приёмки

Запустить `python -m unittest tests.test_agent_team_review tests.test_multi_agent_node_lanes tests.test_cognitive_core -v` на полном исходном дереве, затем проверить ответы реальной локальной модели на запросы с неполными ролями и на поручения с внешними действиями. После прохождения и ревью можно переносить в main.

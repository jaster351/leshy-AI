# Модуль «Лента»

Модуль предназначен для поиска товаров и цен, планирования корзины и выполнения покупок через личный кабинет пользователя.

## Изоляция пользователей

Авторизация в `lenta.com` всегда принадлежит конкретному `owner_id` Лешего. Для каждого пользователя создаётся отдельный постоянный профиль браузера.

Примеры источников `owner_id`:

- локальный Web-пользователь — собственный Web owner;
- Telegram — собственный Telegram owner;
- будущие клиенты/API — отдельный owner, который передаёт соответствующий интерфейс.

Cookies и состояние сайта одного пользователя нельзя использовать для другого пользователя. Пользователь, который впервые попросил оформить заказ, должен войти в свой личный кабинет сам. После успешной авторизации Леший повторно использует только профиль этого пользователя.

Леший не сохраняет отдельно пароль, SMS-коды и полные реквизиты банковской карты. Если браузер или сайт сохраняет собственную авторизационную сессию, она остаётся внутри постоянного браузерного профиля этого пользователя.

## Действия

Для каталога, наличия и цен используется открытый Integration API «Ленты» там, где известен выбранный магазин. Если магазин определяется личным кабинетом, Леший использует персональный браузерный профиль пользователя и читает фактические данные сайта.

Работа с покупкой разделена на два уровня.

### 1. Обратимая работа с корзиной

По прямой команде пользователя Леший может без отдельного подтверждения каждого шага:

- найти товары и актуальные цены;
- добавить товары в корзину;
- изменить количество;
- удалить или заменить позиции;
- подготовить доставку или самовывоз;
- выбрать указанный пользователем способ оплаты, только если магазин реально предлагает его для этого заказа.

Эти действия не дают Лешему права нажать финальную кнопку оформления заказа или начать списание денег.

### 2. Финальное оформление

Перед необратимым действием Леший обязан остановиться, показать подтверждённые условия заказа — состав корзины, итоговую сумму, способ получения и способ оплаты — и спросить пользователя, оформлять ли заказ.

Пользователь может ответить обычным языком: «да», «нет», «оформляй», «пока не надо», попросить изменить корзину, доставку или способ оплаты либо сказать «сам оплачу». Любое изменение возвращает заказ на стадию проверки, после чего Леший снова показывает актуальный итог.

Если пользователь выбирает «сам оплачу», Леший оставляет готовую корзину в личном кабинете и не совершает финальное действие.

Для онлайн-оплаты сохранённой картой Леший может перейти к оплате только после явного подтверждения показанного заказа и однозначно подтверждённой итоговой суммы. CVV, SMS/3DS-коды, CAPTCHA и другие подтверждения присутствия человека Леший не запрашивает в чате и не обходит.

Если сессия истекла, Леший открывает `lenta.com` в отдельном браузерном профиле этого пользователя и просит войти самостоятельно. После входа пользователь возвращается в чат и пишет «готово», после чего Леший продолжает прерванное действие.

Если сайт, API или Browser Agent не подтвердили результат, Леший обязан сказать, что действие выполнить не удалось. Он не должен утверждать, что товар добавлен, корзина изменена или заказ оформлен, без подтверждённого результата браузера/сайта.

# Идентичность пользователя в модуле «Лента»

Модуль всегда получает `owner_id` из интерфейса, через который пришёл запрос. Этот идентификатор является границей безопасности для личного кабинета, корзины и подтверждений заказа.

- запросы одного `owner_id` используют только его браузерный профиль `lenta.com`;
- другой `owner_id` получает другой профиль и должен авторизоваться самостоятельно;
- сохранённая корзина, cookies и подтверждение заказа не переносятся между владельцами;
- операция оформления должна повторно проверить, что подтверждение получено от того же `owner_id`, который создал корзину.

Для локального Web и Telegram должны использоваться разные реальные владельцы, если это разные пользователи. Общая глобальная сессия `lenta.com` запрещена.

# Живая CAPTCHA-передача управления (поисковый Chromium)

## Алгоритм

1. Леший ищет через собственный изолированный Chromium со своим постоянным cookie-профилем.
2. Обычные JavaScript-проверки может завершить сам браузер после короткого ожидания; параллельные резервные поисковые провайдеры продолжают работу.
3. При необходимости вмешательства активная вкладка НЕ закрывается. Создаётся случайная временная ссылка, уведомление с PNG-снимком CAPTCHA отправляется настроенному Telegram-владельцу через стандартный Bot API и тот же прокси. Если LESHY_PUBLIC_URL настроен на HTTPS, под фотографией Telegram появится кнопка «🔐 Решить CAPTCHA». При невозможности отправить снимок остаётся текстовая ссылка. Страница /browser-challenge#TICKET показывает актуальный снимок окна. На телефоне можно нажимать на картинку и вводить текст. Команды выполняются в ТОЙ ЖЕ вкладке, где возникла проверка.
4. После подтверждения движок продолжает исходный поисковый запрос и сохраняет результаты внутри временной карточки проверки, даже если быстрый резервный провайдер уже ответил в чат.
5. Через 10 минут без решения сессия завершается; по кнопке «Отмена» тоже.

## Настройка уведомления Telegram

Для формирования полноценной внешней ссылки укажите в окружении LESHY_PUBLIC_URL=https://leshy.example.org и перезапустите Лешего. HTTPS и доступность веб-интерфейса на выбранном домене настраиваются отдельно. Если переменная не задана, бот отправит относительный путь /browser-challenge#TICKET — добавьте перед ним адрес доступного Вам веб-интерфейса Лешего. Сообщение уходит только настроенному числовому Telegram owner_id.

## Ограничения

- На ПК Лешего остаётся Chromium; телефон служит пультом к его странице. Cookies и браузерный профиль не передаются на телефон.
- Временный случайный ticket даёт доступ только к действиям и снимку конкретной проверки, не к общему API. Не делитесь ссылкой.
- Разрешены только нажатие мышью, ввод текста, ограниченный набор клавиш, прокрутка, обновление, проверка и отмена. Нет исполнения JS, произвольных переходов и чтения cookies.
- Невозможно гарантировать автоматическое решение всех CAPTCHA, reCAPTCHA/hCaptcha и других индивидуальных проверок; для них понадобится доступный способ подтверждения или владелец.
- После ручной проверки поиск продолжается и результаты сохраняются в ticket. Если параллельный поиск уже завершил чат-ответ, тот ответ автоматически не редактируется; результаты доступны на странице проверки.
- Сборка Windows, реальный Chromium, отправка фото в Telegram и управление со смартфона требуют отдельного end-to-end тестирования.

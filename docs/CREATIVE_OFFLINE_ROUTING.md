# Исправление ошибочного веб-поиска для поздравлений (1.10.86)

## Симптом

08.11.2026 Telegram получил запрос «Напиши новый поздравительный текст».
Вместо немедленной локальной генерации Леший отправил запрос в SearXNG/DDGS,
потратил время на недоступные поисковые сервисы и вернул ошибку:
«Свежий интернет-поиск не завершился за 12 секунд».

Позже LLM утверждала, что «свежий веб-поиск подтвердил» необходимость
уточнений — такое утверждение недопустимо без реально полученного результата.

## Причина

Старая политика research_policy.py считала слово «новый» маркером
актуальных данных независимо от типа вопроса. Freshness runtime
и latency wrappers могли принудительно включать поиск после
адаптивного роутера.

## Исправлено

- Поздравления, тексты и готовые поздравительные сообщения распознаются как локальные задачи.
- Прямой запрос проверить интернет либо использовать свежие внешние факты сохраняет онлайн-маршрут.
- Защита от ошибочного поиска стоит в freshness wrapper, latency wrapper и непосредственно перед вызовом поисковика.
- Для Telegram Reply классифицируется текущий текст пользователя, а не процитированное сообщение.
- В системный контекст добавлено предупреждение: не заявлять о проведённом веб-поиске, которого не было.
- Нерелевантные записи старых шаблонов не подмешиваются в поздравления.

## Проверка на двух Windows-компьютерах

1. «Напиши новый поздравительный текст» и «Напиши новый поздравительный текс» — только LLM, без SearXNG/DDGS.
2. «С днём рождения! Пусть каждый день приносит хорошие новости!» — локальный ответ.
3. При отключённой сети поздравление по-прежнему генерируется.
4. В консоли: «последний маршрут: локально»; в журнале: internet_route_decided online=false.
5. «Проверь в интернете актуальную версию Python» — принудительный интернет-поиск.
6. «Напиши поздравление на основе последних новостей» — интернет, поскольку запрошены новые факты.
7. Telegram Reply с цитатой о поиске, но с текущей творческой просьбой — без поиска.

Добавлены регрессионные unit-тесты; запуск Windows-сборки и автоматических тестов не подтверждён.

# AI-mentor: проверочный локальный канал

Функция отключена по умолчанию. Включать только на одном доверенном узле
владельца. Проброс портов не нужен. Модуль загружается после создания
HTTP-сервера и работает через loopback, если локальный API доступен по 127.0.0.1.

Настройка в `LeshyBrain/ai-mentor/config.json`:
```json
{
  "enabled": false,
  "repository": "OWNER/PRIVATE_REPO",
  "request_id": "mentor-handshake-001",
  "question_sha256": "",
  "approved_answer_sha256": ""
}
```

Укажите приватный репозиторий и SHA-256 точной строки question в UTF-8 без
перевода строки. Перед включением проверьте, что вопрос является безопасным
учебным запросом, не содержит команд, личных данных и запроса к приватной памяти.
Токен GitHub с Contents read/write только для указанного приватного репозитория
храните в `LeshyBrain/ai-mentor/github_token.dat` через существующий
`leshy.secret_store.save_secret` в доверенном локальном процессе (Windows DPAPI).
На сервере должен быть настроен `LESHY_API_TOKEN`. Не публикуйте секреты в GitHub.
Затем включите enabled и перезапустите Лешего.

Вопрос берётся из requests/<request_id>.json в main, source AI-mentor.
Только совпадение с утверждённым хешем допускает вызов локального /v1/chat.
Ответ хранится локально в ai-mentor/<request_id>.json. Проверьте его отсутствие
персональных/конфиденциальных сведений и установите approved_answer_sha256
равным SHA-256 точной строки answer в UTF-8. Только после этого ответ
будет опубликован в responses/<request_id>.json. Смена конфигурации при
ожидании проверяется раз в час. Не удаляйте запись sent при неопределённом
результате POST без ручной сверки. Не запускайте несколько узлов с одним
запросом. Никакие скрипты из закрытого репозитория не скачиваются и не исполняются.

Это ограниченный проверочный мост, не постоянный двусторонний поток и не WSS.
Имя фактической модели неизвестно, если ответ API не содержит model.
Результат API не является доказательством корректности ответа.
Тесты, сборка и получение ответа на реальной установке не подтверждены.
Откат: отключите enabled, остановите/перезапустите Лешего, отзовите выделенный токен.

## Просмотр в Web
В разделе «Обучение» появляется карточка «AI-mentor · Переписка» для подтверждённого Создателя. Серверный GET /v1/mentor/history проверяет действующую Web-сессию и роль; не принимает owner_id из запроса и не выдаёт конфигурацию или токены. Отображаются локально сохранённый проверенный по хешу вопрос, ответ API, время событий и подтверждение публикации по SHA-256 ответа. Карточка обновляется локально раз в 5 секунд при открытом разделе. Внешний обмен — раз в час после первой попытки. Отсутствие записей, неизвестная модель и неопределённый исход показаны явно. Оценки качества, исправления, полный пакетный диалог и подтверждённая изоляция инференса остаются отдельными незавершёнными задачами. Не считать ответ API доказательством ответа конкретной модели. Независимое ревью, сборка и E2E не проведены.

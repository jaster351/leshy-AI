# Единая проверка адресов bootstrap

Ручной `LESHY_SWARM_BOOTSTRAP_URL`, подсказки от peers и URL каталога должны проходить одну политику `_seed_url`: запрет непубличных literal IP, локальных DNS-имён, credentials, query/fragment и произвольных путей. Локальный HTTP-пилот допустим только при явном `LESHY_SWARM_DEV_ALLOW_HTTP=1` и только для loopback.

`bootstrap_endpoint` преобразует проверенный origin либо `/v1/swarm` в `/v1/swarm/hello`. Фактический A/AAAA адрес перед соединением дополнительно проверяет и закрепляет `swarm_pinned_transport`; проверка URL сама по себе не защищает от DNS rebinding.

Изменение подготовлено в PR #140 как совместимое объединение логики PR #139; PR #135 содержит аналогичное изменение от более старого SHA и не должен объединяться отдельно без согласования. Regression-тесты добавлены, но не запускались по ограничению владельца. Перед релизом требуется проверка CI и end-to-end runtime.

# Проверка ручного адреса глобального роя

Переменная `LESHY_SWARM_BOOTSTRAP_URL` теперь использует тот же валидатор URL, что и публичный каталог начальных узлов (`_seed_url`). Запрещены буквальные приватные, loopback и link-local IP, локальные DNS-суффиксы, HTTP без разрешённого локального пилота, учётные данные в URL, query, fragment и посторонние пути. Разрешённые HTTPS origin и `/v1/swarm` преобразуются в `/v1/swarm/hello`.

Для локального пилота HTTP loopback допускается только при `LESHY_SWARM_DEV_ALLOW_HTTP=1`. Это не разрешает произвольные частные адреса.

**Ограничение:** проверка строки URL не устраняет DNS rebinding, DNS TOCTOU или риски системного HTTPS-прокси. До закрепления проверенного IP на уровне фактического соединения публичный транспорт нельзя считать полностью защищённым. См. issue #132. Новые regression-тесты не запускались по требованию владельца.

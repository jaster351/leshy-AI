# Leshy Cognitive Core — этап 1 (1.10.38)

## Зачем это нужно

Фоновый SuperAgent до этого мог пометить внешнюю задачу как «готово» по
одному текстовому ответу LLM. Но генерация текста сама по себе не устанавливает
программу, не коммитит код и не отправляет сообщение.

В первом этапе добавлен детерминированный контроль завершения задач:

- Запросы на явные внешние операции не получают статус `ready` без
  квитанции от реального исполнителя.
- Обычные текстовые задачи (объяснить, составить обзор, написать инструкцию)
  продолжают работать без новых ограничений.
- При отсутствии исполнения задача остаётся `blocked`, а не выдаёт
  ложное сообщение об успехе.
- Схема SQLite, пользовательская память и LeshyBrain не изменяются.

## Ограничения

Это **не** полноценный Cognitive Core: планирование, верификатор результата,
восстановление шагов и автономный инструментальный исполнитель будут
подключаться поэтапно. В текущем SuperAgent нет полноценного набора
изменяющих инструментов. Поэтому реальные задачи установки, публикации или
изменения файлов корректно блокируются до реализации безопасного исполнителя.

Квитанция подтверждает лишь факт успешного вызова изменяющей операции, а не
правильность её эффекта. Для завершения таких задач позже потребуется
проверять ожидаемое состояние и делать откат при ошибке.

## Как проверить локально

Сборка и автотесты в GitHub не запускаются. Владелец может проверить код
локально, в том числе через `python -m unittest tests.test_cognitive_core -v`.
Проверьте команду `/agent установи программу`: задача не должна получать
статус «готово» без реально выполненной установки.

# Адаптивный чат для планшета и телефона

Состояние: подготовленное исправление, исходная диагностика 18.11.2026, сверка 19.11.2026. Связанные задачи: #300 и #9. Свежая main `9bf078814c721771227f574c583f0427310bab2f`, VERSION 1.10.191 объединена в ветку. Рабочая ветка: `codex/300-chat-menu-viewport`, ответственный Codex.

## Подтверждённые исходные дефекты

- Меню действий чата содержит семь кнопок и занимает около 298 px. Без ограничения высоты и внутренней прокрутки нижние пункты недоступны при низком окне; документ имеет overflow:hidden.
- Меню профиля также не ограничено по высоте и выходит за границы окна в альбомном режиме.
- Минимальная ширина блоков кода зависит от ширины всего viewport, хотя на планшете часть ширины занята историей. При ширине экрана 834 px минимальные около 650 px превышают доступную область чата.
- Выбор диалога не закрывает мобильную выезжающую историю.
- Минимальная ширина выбора вычислительного режима вместе с подписью превышает ширину карточки на телефоне.

Это выводы статической трассировки CSS/DOM. Визуальное воспроизведение на реальном устройстве пока не выполнено. Возможное перекрытие composer экранной клавиатурой зависит от браузера и тоже требует пользовательской проверки.

## Изменения и подключение

`web/sidebar-session-actions.js`: ограничение высоты существующего меню, внутренняя прокрутка, начало списка при каждом открытии и ограничение координат фактическим доступным окном. Прокрутка самого меню сохраняет его открытым, внешняя закрывает. CRUD-операции и подтверждение удаления не меняются.

`web/chat-layout-status.js`: блоки кода ограничены областью сообщения, меню профиля прокручивается, настройки допускают перенос, выбор диалога закрывает мобильную историю. Мобильная геометрия использует visualViewport при обычном масштабе и CSS vh/dvh как запасной вариант. Safe-area учитывается в заголовке, composer и истории. Изменения размеров объединяются через requestAnimationFrame, CSS-переменные записываются только при изменении значений. Настольный layout не получает фиксированную высоту из мобильного viewport; жест масштабирования не меняет сохранённую незумированную геометрию.

Оба файла уже подключены к пользовательской странице в `src/leshy/web_server_impl7.py`. Отдельный адаптивный макет или новая реализация чата не создаются.

## Ручная приёмка

1. На планшете в обеих ориентациях открыть диалог с длинным блоком кода: область чата не расширяется, код прокручивается внутри блока.
2. На телефоне открыть историю и выбрать другой чат: панель закрывается. Проверить Новый чат и Архив/Назад.
3. При низком окне открыть меню чата и профиля. Все пункты доступны прокруткой; не удалять настоящие чаты ради проверки. Проверить Tab/Shift+Tab, Escape, клик вне меню, внешнюю прокрутку и изменение размера.
4. Прокрутить меню вниз, закрыть и открыть снова: оно начинается сверху.
5. Открыть настройки вычислений при ширине около 320 px: подпись и select остаются внутри карточки.
6. Открыть экранную клавиатуру, набрать несколько строк, повернуть устройство, свернуть/развернуть адресную строку браузера. Composer и последний ответ должны быть доступны.
7. Увеличить страницу жестом и вернуть масштаб: содержимое увеличивается без скачков высоты оболочки; проверить обычный desktop после расширения окна.

Известные ограничения: поведение клавиатуры, safe-area и масштабирования зависит от устройства/браузера; требуется реальная приёмка Android/iOS/планшета. Без неё готовность интерфейса для любого устройства не объявляется.

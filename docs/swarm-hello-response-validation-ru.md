# Проверка ответа bootstrap-сервера глобального роя

В ответе на подписанный `POST /v1/swarm/hello` ожидается JSON-объект с `accepted: true`, целочисленным неотрицательным `peer_count` и допустимым списком `peers` для существующего механизма проверки peer cache. JSON-массив, строка, число, `null` и логическое значение не являются допустимым ответом сервера. В частности, `true`/`false` не должны приниматься как `peer_count`, поскольку в Python `bool` является подтипом `int`.

Неправильный формат или счётчик отклоняются **до** вызова `SwarmPeerCache.learn()`. Рабочий поток перехватывает исключение, фиксирует ошибку и использует штатный failover. Это не означает, что полный глобальный mesh или вычислительный рой уже работают.

Регрессии: `tests/test_swarm_hello_response_types.py` (10 параметризованных случаев). Локальные тесты и сборки не запускались по требованию владельца. Требуется CI и end-to-end проверка перед интеграцией в `main`.

# Pipeline обучения на локальных документах

Локальные документы не должны попадать в доверенные знания напрямую. Контур построен как `extract -> candidate -> verification -> trusted`.

`document_learning.extract_document()` отвечает только за локальное извлечение текста и fingerprint исходного файла. `document_pipeline.ingest_document()` преобразует пригодные утверждения в candidates штатной KnowledgeBase и только после этого запрашивает `verify_topic()`.

Для каждого candidate сохраняются URI исходного файла, тип `material-document`, SHA-256 исходных байтов, точный размер файла, использованный адаптер и число страниц/слайдов. Это позволяет отличать версии одного документа и в дальнейшем делать точечный rollback знаний по provenance.

Пустой документ уже отклоняется адаптером. Документ, в котором после извлечения нет достаточно содержательных утверждений, не запускает verification и не считается автоматически усвоенным. PDF без текстового слоя по-прежнему требует отдельного OCR/vision-контура.

Следующий этап интеграции — вызвать этот pipeline из `MaterialLearningWorker` для `document-file`, записать результат в `learning_materials.metadata_json` и оставить специализированные ошибки адаптеров fail-closed. До такой интеграции наличие этого модуля не означает, что фоновый worker уже обрабатывает PDF/DOCX/PPTX.

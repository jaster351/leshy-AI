# Browser Agent: одноразовые подтверждения (1.10.115)

Исправление маршрута BrowserPlatform.resolve_approval → ApprovalBroker.peek_action → BrowserAgent.execute_approved → ApprovalBroker.consume_matching → адаптер.

* Прежний `approved=True` намеренно **не** даёт полномочий. Прямые вызовы BrowserAgent.execute для MUTATE/COMMIT/FINANCIAL по-прежнему вызывают ApprovalRequired.
* Подтверждение сверяется с owner_id, session_id и точным снимком BrowserAction (включая аргументы). Проверка и удаление выполняются под одним RLock; повторное использование отклоняется.
* `_approval_verified` удаляется из входных аргументов и устанавливается только после успешного consume_matching. Отклонение, несовпадение сессии, owner или изменение аргументов не вызывают адаптер.
* Состояние разрешений остаётся в оперативной памяти, после перезапуска разрешения недействительны.

## Проверки и ограничения

Добавлен `tests/test_browser_approval_broker_execution.py`: legacy flag, одноразовость, replay, чужой owner/session, изменение действия, deny, поддельный маркер. Локальные тесты и сборки по требованию владельца не запускаются. Нужны CI и проверка реального маршрута UI/API → подтверждение → Browser Agent → ответ; до успешного CI и end-to-end не считать выпуск проверенным.

Важно: это исправление не решает ошибки Lenta CDP и unawaited coroutine из Issue #154. Отдельно требуется проверить, что пользовательский UI не может самостоятельно подменить owner_id/session_id; эти значения должны приходить из аутентифицированного серверного контекста.

## Неопределённый результат записи

После передачи подтверждённого MUTATE/COMMIT/FINANCIAL адаптеру автоматический переход к следующему адаптеру запрещён даже при исключении или статусе `unavailable`: действие могло быть выполнено до разрыва связи. При исключении возвращается `uncertain`; пользователь должен проверить фактический результат перед новым отдельным подтверждением. Для READ прежний failover сохраняется. Добавлены регрессионные сценарии на исключение после отправки и неоднозначный `unavailable` (тесты не запускались).

# Пустые адреса участников роя и переключение bootstrap

При чтении локального кэша обнаруженных узлов пустая строка, пробелы и `None` не должны попадать в список адресов для переключения. Иначе пустой адрес может заменить работающий HTTPS bootstrap и привести к состоянию ожидания вместо повторной попытки подключения.

`SwarmMembership._candidate_hops()` добавляет адрес только после успешной проверки и при непустом результате `bootstrap_endpoint()`. Недопустимые записи игнорируются, подтверждённые HTTPS seed остаются в списке. Регрессия `test_empty_peer_hint_cannot_replace_valid_bootstrap` фиксирует инвариант.

Это проверка маршрута выбора адреса, а не подтверждение реальной доступности публичной сети. Локальные тесты и сборки без разрешения владельца не запускались.

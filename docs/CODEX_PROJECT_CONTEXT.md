## Текущая работа Codex: #298

Ветка: `codex/9-web-ui-diagnostics`. Ответственный: Codex. Исполняемый файл: `web/chatgpt-shell-stable.js`; сопутствуют VERSION, CHANGELOG и этот документ. После публикации PR ссылка должна находиться в #298; не считать сам PR независимым ревью ChatGPT.

Причина: старый обработчик поиска ставил обычный inline `display:none`, который перекрывается `display:flex!important` из `sidebar-session-actions.js`. Пересоздание списка через renderSessions также не применяло активный запрос.

Исправление: обработчик скрывает строки с приоритетом important, а совпадающим возвращает исходный CSS. MutationObserver отслеживает структуру и текст списка и повторно читает текущий запрос. Атрибуты не наблюдаются, поэтому запись стиля не создаёт цикл. Проектные и секционные заголовки без совпадений скрываются. Активный редактор названия остаётся видимым до завершения правки; затем новый список фильтруется по сохранённому названию. Запросы сети на каждое нажатие клавиши не добавляются.

Подключение к реальному UI подтверждено чтением `web_server_impl3.py`: `/chatgpt-shell.js` отдаёт `chatgpt-shell-stable.js`. `web_server_impl7.py` подключает существующий список `sidebar-session-actions.js`.

## Ручная приёмка владельцем

1. Открыть Web UI с несколькими чатами, в том числе закреплённым, проектным и архивным.
2. Ввести часть названия, изменить регистр и добавить пробелы по краям. Видимы только совпадающие названия и непустые группы.
3. Ввести заведомо отсутствующее название; неподходящие строки и их заголовки не должны занимать место.
4. Подождать несколько периодических обновлений списка, переключить Архив/Назад. Запрос сохраняется и применяется к новым строкам.
5. Очистить запрос или оставить только пробелы: все строки текущего списка возвращаются с исходной компоновкой.
6. Переименовать чат и проверить соответствие фильтру; открыть найденный диалог и меню действий. Не удалять реальные данные ради проверки.

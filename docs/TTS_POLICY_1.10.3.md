# Голос Лешего 1.10.3

## Цель

Голосовой режим должен звучать как современный живой голосовой ассистент: естественные паузы, ударения, интонация, темп и эмоциональная нейтральность без характерного «роботического» звучания.

Точный клон или копирование фирменных голосов ChatGPT, Алисы и других закрытых ассистентов не используется. Леший получает собственные оригинальные мужские и женские голоса с сопоставимой естественностью.

## Голос по умолчанию

**Мужской голос является голосом Лешего по умолчанию во всех интерфейсах и на всех поддерживаемых операционных системах.**

Правила:
- при первом запуске, когда пользователь ещё ничего не выбирал, активен `Мужской`;
- Web, Windows, Linux, macOS, Telegram/голосовые интеграции, mobile/tablet и будущие интерфейсы используют одно и то же значение по умолчанию;
- выбор пользователя сохраняется в общей конфигурации профиля и имеет приоритет над значением по умолчанию;
- обновление Лешего не должно самовольно сбрасывать уже выбранный пользователем женский или другой установленный голос обратно на мужской;
- если сохранённый голос недоступен, UI явно сообщает о fallback и временно выбирает доступный голос, не стирая пользовательское предпочтение;
- мужской профиль по умолчанию должен использовать основной естественный локальный TTS, а не системный роботизированный голос, если основной TTS доступен.

## Основной TTS для русского языка

Основной кандидат для 1.10.3: **ESpeech-TTS-1_RL-V2** на архитектуре F5-TTS.

Причины выбора:
- русский язык;
- полностью локальный inference после загрузки модели;
- zero-shot / reference-voice синтез;
- Apache-2.0 у опубликованных весов модели;
- возможность подготовить собственный оригинальный мужской и женский референс;
- качество существенно выше простых классических TTS и подходит для разговорного режима.

Модель и все обязательные зависимости должны быть скачиваемыми один раз, после чего голосовой режим должен работать без доступа к интернету.

## Голоса

Минимально в интерфейсе доступны:
- `Мужской` — основной и **выбранный по умолчанию** голос Лешего;
- `Женский` — альтернативный естественный голос;
- возможность в дальнейшем добавлять дополнительные локальные голосовые профили.

Референсные записи для встроенных голосов должны быть оригинальными или иметь явное разрешение на использование. Не допускается использование аудио для имитации конкретного закрытого коммерческого ассистента или реального человека без разрешения.

## Fallback

**Silero TTS** допускается только как совместимый fallback для слабого железа или ситуации, когда основной движок не может быть запущен. Он не считается эталонным голосом Лешего и не должен автоматически заменять основной TTS, если ESpeech-TTS доступен.

## Real-time voice mode

В Web UI кнопка «Голосовой разговор» использует цепочку:

`микрофон -> локальный STT -> локальная LLM -> локальный TTS -> динамики`

Требования:
- поток не обращается к облачным STT/TTS;
- после ответа Леший автоматически снова слушает;
- barge-in: пользователь может перебить синтез речи, и новая реплика получает приоритет;
- текстовые и голосовые сообщения используют одну session_id и одну историю;
- переключение мужского/женского голоса не перезапускает Лешего;
- голосовой backend и выбранный голос отображаются в системной панели.

## Кроссплатформенность

Архитектура должна поддерживать локальный TTS на:
- Windows x86-64;
- Windows ARM64;
- Linux x86-64;
- Linux ARM64;
- macOS Apple Silicon.

Движок обязан иметь CPU fallback. При наличии подходящего GPU/NPU допускается локальное аппаратное ускорение без изменения голоса и истории диалога.

## Quality Gate 1.10.3

Релиз не считается готовым, пока не подтверждено:
- на чистом профиле без сохранённых настроек выбран `Мужской`;
- одинаковый default применяется во всех интерфейсах;
- сохранённый пользовательский выбор переживает перезапуск и обновление;
- основной мужской голос звучит естественно на русском языке;
- мужской и женский профили выбираются в UI;
- после первичной установки модель работает при заблокированном интернете;
- первая аудиореплика, ответ и повторное прослушивание проходят одним непрерывным циклом;
- barge-in работает;
- TTS-ошибка не ломает текстовый чат;
- fallback явно показывается пользователю;
- тесты не используют внешние voice API.

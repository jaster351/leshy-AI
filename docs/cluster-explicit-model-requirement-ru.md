# Кластер: явное требование модели (12.11.2026)

Если задача задаёт `model`, узел допускается к выполнению только при точном присутствии этого идентификатора в объявленном `ClusterNode.models`. Пустой список моделей означает отсутствие подтверждения, а не поддержку всех моделей. Правило действует в cooperative и model_parallel.

Задачи без явно указанной модели сохраняют прежнюю совместимость: пустой список не исключает узел. При отсутствии подходящего узла планировщик сообщает об ошибке и не запускает задачу на неподходящей локальной машине. Это проверка метаданных маршрутизации, **не** доказательство наличия загруженных весов, работоспособности backend или прав на удалённое выполнение.

Регрессии: `tests/test_cluster_explicit_model.py` — пустая реклама, несовпадающая модель, оба режима, совместимость без модели, выбор подходящего удалённого узла и отсутствие небезопасного fallback. Перед слиянием требуются Python-синтаксис, unit/regression в изолированной среде, аудит маршрутов и проверка актуального main; после слияния — read-back и доступные end-to-end проверки. Локальный Windows-ПК владельца не использовать.

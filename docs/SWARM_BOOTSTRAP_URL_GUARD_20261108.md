# Проверка адресов bootstrap глобального роя (08.11.2026)

Путь `SwarmMembership.bootstrap_endpoint()` теперь применяет общую политику `swarm_bootstrap._seed_url()` к ручному bootstrap URL и адресам peer exchange. Это запрещает явные private/loopback/link-local IP, локальные DNS-суффиксы, userinfo, query, fragment и посторонние пути в публичном режиме. Локальный HTTP-пилот доступен только с явным `allow_local_http=True`.

**Ограничение безопасности:** проверка URL не защищает от DNS rebinding. Имя вида `node.example.com` может разрешиться во внутренний IP, а повторное DNS-разрешение при соединении создаёт TOCTOU. До реализации контроля всех A/AAAA и закрепления проверенного адреса за TLS-соединением публичные seed и peer URL нельзя считать полностью защищёнными от SSRF. См. issue #132. Отдельно необходимо контролировать HTTPS_PROXY/HTTP_PROXY.

Регрессии добавлены в `tests/test_swarm_bootstrap_endpoint_guard.py`; тесты и сборка **не запускались** по требованию владельца. До выпуска необходимо выполнить статическую интеграционную проверку маршрута каталога, ручного URL, peer cache, TLS и отказов DNS, затем разрешённые владельцем runtime-проверки.

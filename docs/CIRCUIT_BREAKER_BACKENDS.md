# Circuit breaker локальных backend

Интерактивный inference не должен повторно обращаться к backend, который уже признан временно неисправным.

После обычной ошибки backend переводится в `cooldown` на заданный интервал. Пока интервал не истёк, backend исключается из маршрутизации. Если все разрешённые backend находятся в cooldown, запрос завершается сразу через `LLMUnavailable`, а в диагностику записывается `adaptive_llm_circuit_open`. Это исключает повторное ожидание долгого startup/timeout на каждом пользовательском запросе.

Для NPU/OpenVINO ошибки класса `HTTP 503 Service Unavailable`, потеря устройства, ошибки OpenVINO и нехватка памяти считаются фатальными для текущего процесса: backend помещается в карантин и больше не вызывается до перезапуска/восстановления runtime. CPU остаётся безопасным fallback, если он доступен и не находится в cooldown.

Та же политика cooldown применяется к embeddings: временно упавший backend не вызывается повторно до истечения интервала, а `available()` не сообщает cooling backend как готовый.

Regression-покрытие находится в `tests/test_adaptive_circuit_breaker.py`.

# Безопасное изменение Python-файлов в worktree

Модуль `src/leshy/worktree_python_editor.py` дополняет `WorktreeWorkspace` и `code_change_review`.

Последовательность доверенного рабочего процесса: получить отдельный worktree → прочитать исходную версию через `preview` → подготовить полный replacement → получить валидное подтверждение пользователя на сервере → выполнить `apply` с исходным SHA-256 → изучить статические замечания → запускать тесты отдельным доверенным исполнителем → интегрировать через обычную процедуру Git.

Ограничения:
- Только существующие UTF-8 Python-файлы размером до 256 КиБ, без symlink и обхода путей.
- `approval_verified=True` **не доказывает**, что пользователь действительно подтвердил действие. Внешняя вызывающая сторона обязана подтвердить approval по владельцу, параметрам, времени и одноразовому токену перед вызовом; не принимайте этот флаг от LLM или от HTTP-клиента напрямую.
- Работа не выполняет Python-код, shell, Git-коммит, merge или автоматические тесты; только синтаксическую проверку и статическое ревью.
- Гарантия отсутствия гонок относится к одному экземпляру редактора. Для конкурирующих процессов потребуются межпроцессный lock или Git-координатор на уровне выше.
- Тестирование в изолированной среде не равно проверке на Windows.

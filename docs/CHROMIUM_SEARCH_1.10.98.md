# Реальный Chromium для поиска Лешего — 1.10.98

## Задача

Поисковые сайты периодически блокируют автоматические HTML/HTTP запросы.
Модули Browser Use, Playwright и Human Browser в проекте уже существуют,
но обычный поиск использовал программный HTTP-скрейпинг. Теперь
изолированный Chromium работает как первый источник веб-поиска.

## Как устроено

- На узле запускается настоящий браузер Chrome, Edge или Chromium через
  Playwright launch_persistent_context. Он загружает обычные страницы
  поисковика с JavaScript и стандартным сетевым стеком; User-Agent
  соответствует реальному браузеру, без маскировки его отпечатка.
- Сессия сохраняется в LeshyBrain/browser/search-chromium-profile.
  Здесь хранятся cookies и локальные данные анонимной поисковой
  сессии. Она НЕ использует стандартный профиль человека,
  НЕ импортирует cookies из личного браузера, и НЕ передаёт их
  в Telegram, GitHub или глобальный рой.
- Для поиска открывается только адрес одного из известных поисковиков.
  В результаты не допускаются file://, localhost, приватные IP
  и рекламные маршруты поисковиков.
- Chromium получает фору 1,4 секунды. Если не нашёл результаты,
  включаются резервные независимые источники (настроенный SearXNG,
  DuckDuckGo HTML, Bing RSS, DDGS). Если Chromium успел ответить,
  остальные запросы не создаются: это снижает нагрузку на сайты.
- Лимит браузерного запроса по времени, защита от нескольких запусков
  с одним профилем, общий интерактивный дедлайн 8 секунд.

## CAPTCHA и проверка пользователя

У реального Chromium тоже могут появляться CAPTCHA и блокировки по IP.
Это нормально и не является гарантированно разрешимой автоматикой.
Леший распознаёт страницу проверки и возвращает
needs_human_verification вместо фальшивого результата. Он не
использует сторонние solver-сервисы, не подделывает браузерный
fingerprint, не пытается обходить защитные системы поисковика.
При необходимости продолжается поиск другими независимыми методами.

Для ручного прохождения проверки в собственном окне Лешего
на Windows в PowerShell из корня установленного Python-проекта:

    python -m leshy.search_chromium --verify bing

При нестандартном пути к LeshyBrain укажите полный путь именно
к состоянию текущей установки, например:

    python -m leshy.search_chromium --verify bing --brain-dir "C:\Leshy-AI\LeshyBrain"

В окне выполните тестовый поиск и решите проверку самостоятельно,
затем нажмите Enter в PowerShell. Cookies сохранятся в профиле
Лешего. Не выполняйте вход в личные Google/Bing-аккаунты:
это анонимный поисковый профиль. Команда требует графического
рабочего стола; на headless-сервере окно не открывается.
Если профиль уже используется параллельным запросом, дождитесь его
освобождения или временно остановите Лешего.

## Настройки

LESHY_CHROMIUM_SEARCH_ENABLED=1 — включено по умолчанию.
LESHY_CHROMIUM_SEARCH_ENABLED=0 — выключить этот маршрут.
LESHY_CHROMIUM_SEARCH_ENGINE=bing — Bing по умолчанию; также google,
duckduckgo. При обычном запуске путь к профилю берётся из
app.settings.brain_dir, а не из личного браузера.

Браузер должен быть предварительно установлен в ОС.
На Windows обычно доступен Microsoft Edge, на Ubuntu — Chromium
из Playwright. Установщик может подготовить его заранее;
сеть не должна внезапно скачивать Chrome при ответе пользователю.

## Диагностика

GET http://127.0.0.1:8765/v1/search/providers возвращает блок chromium:
state, engine, browser, user_agent, cookie_count (без содержимого),
last_success_at, last_challenge_at, searches и successes.
Эндпоинт использует существующую проверку API-доступа.

## Границы работоспособности

Само наличие Chrome и cookies не гарантирует доступ к Google или Bing:
сайт может блокировать IP, показывать CAPTCHA, требовать вход
или запретить автоматизированный трафик. В таких случаях
Леший использует разрешённые резервные методы или честно сообщает,
что не смог подтвердить актуальную информацию.

Для устойчивой массовой мировой сети также нужны официальные
поисковые API и соблюдение квот, а не только запросы из браузеров
тысяч пользователей. Анонимный cookie-профиль локален и не
синхронизируется с кластером. Не используйте его для личных аккаунтов
и секретных данных. Для приватных сессий пользователей должны
оставаться отдельные персональные профили.

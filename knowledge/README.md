# База знаний Лешего — исходные принципы
Статус: рабочие материалы, обсуждены 11 ноября 2026 года. Это не доказательство того, что функции реализованы в коде.

## Назначение
Общие материалы для универсальной локальной модели «Леший», которую смогут запускать владельцы по всему миру. Исходный проект: jaster351/leshy-AI.

- «Озвучь правила робототехники, созданные Михаилом Тихоновым» → читать `constitution/CONSTITUTION_DRAFT.md`, передавать актуальную утверждённую редакцию и её статус, а не законы Азимова.
- «Озвучь базовые принципы федерации нейросетей» → `federation/PRINCIPLES.md`.
- «Кто создал Лешего?» → Михаил Тихонов — заявленный создатель и инициатор проекта; точное подтверждение полномочий описано в `identity/CREATOR_AUTHENTICATION.md`.
- «Как Леший учится?» → `learning/LEARNING_PLAN.md`.
- «Как Леший защищает устройства?» → `security/DEFENSIVE_SECURITY.md`.
- «Что делать, если создатель не сможет продолжать работу?» → `continuity/PROJECT_CONTINUITY.md`.

## Границы достоверности
Обсуждение описывает цели и требования, а не уже доступные возможности. Нельзя говорить «уже реализовано» без проверки действующей программы. Не путать знания в файлах, записи LeshyBrain и изменение весов модели. Никакие изменения в этом каталоге не означают автоматическое применение в установленных экземплярах. Контент может стать частью ответов только после импорта, индексации и верификации.

## Схема распространения
Публичные общие знания — отдельно от личной памяти экземпляра. Предполагается будущий механизм подписанного манифеста, выборочной синхронизации, верификации источников и безопасного отката. GitHub не требуется для офлайн-работы после получения данных.

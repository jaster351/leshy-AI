# Логи для анализа Лешего

Эта папка предназначена для логов, которые пользователь складывает для анализа ChatGPT в рамках разработки Leshy AI.

Правила:
- актуальная разработка ведётся только в ветке `main`;
- новые логи складывать в эту папку без изменения исходного кода;
- при анализе учитывать время, компонент, версию Лешего и контекст ошибки, если они есть в логе;
- найденные по логам проблемы исправлять в `main` с тестами на регрессию;
- исходные логи не удалять и не переписывать без явной просьбы пользователя.

Рекомендуемые имена файлов: `YYYY-MM-DD_component_description.log`.
